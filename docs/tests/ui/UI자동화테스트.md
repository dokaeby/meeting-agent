# UI 자동화 테스트

Playwright Chromium, Vite web + FastAPI test 서버. 테스트 모드 provider/SMTP만 사용, 외부 발송 금지. locator는 role/name/label 우선, CSS 세부 구조에 의존하지 않는다.

| ID | 여정 | 확인 |
|---|---|---|
| E01 | 가입→확인→회사 생성→로그인 | 세션/회사 이름 표시 |
| E02 | 회사 생성→직원 초대→수락 | 정확한 이메일과 역할, 초대 재사용 거부 |
| E03 | 회의 등록→녹취 업로드→요약 | 상태 진행, 결정사항·근거 표시 |
| E04 | 수정→승인→발송 | 새 버전, 수신자 확인, accepted 상태 |
| E05 | 2회사 전환/직접 URL 조작 | 다른 회사 제목/파일 미노출 |
| E06 | 일반 직원 로그인 | 초안·원문·관리 설정 숨김, 확정본만 표시 |
| E07 | API 429/500/연결 끊김 | 오류 안내·명시적 재시도 |
| E08 | 모바일 390px/키보드 | 수평 넘침 없이 주요 작업 수행 |
| E09 | 이전 회사 요청 늦게 완료 | 현재 회사 화면 불변 |
| E10 | 토큰/연동 미설정 | 연결 필요 안내, fake 성공 표시 금지 |

실행: npm run test:e2e. 실패 시 trace/screenshot 첨부. 웹/서버는 테스트 스크립트가 시작·종료하고 127.0.0.1에 바인딩한다. 실제 외부 계정 검증은 별도 smoke 절차이며 본 UI suite에 포함하지 않는다.
